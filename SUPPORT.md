# Support

Use this repository's GitHub Issues for bugs and usage questions. Search existing issues before opening a new one. Include the affected operation, browser, and a redacted error message.

For setup and operation, start with the [README](README.md). Never attach credentials, deployment environment files, or attendee data to an issue. Report security vulnerabilities privately using [SECURITY.md](SECURITY.md).

## Microsoft support policy

Support for this project is limited to the resources listed above.
